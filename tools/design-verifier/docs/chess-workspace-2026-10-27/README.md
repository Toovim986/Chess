# Интерфейс шахмат: картинки вместо описаний

27.10.2026. Для профиля `chess` пульт сокращён до четырёх вкладок. Каждая строится из последней импортированной ревизии: манифест, PNG и `ds-audit.json`.

- **Главная** — 6 экранов, четыре числа (экраны, экземпляры Poker lib, цвета вне DS, пробелы DS), открытые замечания и ссылки на источники.
- **Макеты** — галерея ревизии: экраны, карты передачи, обзор и «Экспериментариум». В «Экспериментариуме» — ранние концепты нейросети (3 ревизии, 8 картинок), сгруппированные по исходной ревизии и помеченные как сделанные без DS. Проверки показаны строкой статусов, замечания свёрнуты. Архив ревизий появляется только для прежних ревизий, которые не являются концептами.
- **Карта передачи** — карты экранов из ревизии, переключатель слева, JSON карты и узел Figma.
- **Дизайн-система** — компоненты Poker lib с фрагментами экранов, пробелы DS, цвета, шрифты, локальные компоненты, свёрнутые правила процесса.
- **Референсы** — исследование экрана партии: 10 скриншотов с App Store (Chess.com, ChessGold, Chess Clash, Chess Royale, Clash of Kings, Lichess) рядом с нашим экраном, 7 перенятых паттернов с местом применения и список того, что не взято. Данные: `verifier/public/chess/references/references.json`.

Любая картинка открывается на весь экран, между картинками группы можно листать стрелками. Прямые ссылки: `?audit=<id>`, `?view=screen-map`, `?view=ds`.

Скрыты для шахмат: «Правила и источники», «Расхождения», «История запусков», «Пометки». Их данные и API не удалены, профиль Poker показывает прежний интерфейс.

Фрагменты компонентов в `verifier/public/chess/ds/` вырезаны из 2× экспортов ревизии `chess-ds-2026-10-27-v3`. Прежняя шахматная карта по концептам нейросети (`chess-screen-map.*`, `screen-map/chess.json`, `screen-map/ds/`) и предыдущие версии изменённых файлов сохранены в `previous/`.

Проверено 27.10.2026: JS-тесты 27/27, Python 17/17; сценарий в headless Edge через CDP (вкладки, окно просмотра и стрелки, архив, переключение карт, 18 карточек DS без битых изображений, ошибок JS нет); пустой профиль на временном хранилище; ширина 390 px без горизонтального переполнения. `verifier/test/browser-check.mjs` переписан под новый интерфейс; в этом окружении не запускался — Playwright не установлен.
