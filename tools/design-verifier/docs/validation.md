# Проверка выделенной версии · 27.10.2026

Из корня подготовленного пакета выполнены `npm.cmd test` — 25 тестов PASS, и `python -B -m unittest discover -s engine -p 'test_*.py'` — 17 тестов PASS.

Проверены изоляция профилей, пустой Chess без подставленных Poker-данных, API контекста, сохранение FAIL, родительские ревизии, перезапуск, скачивание/хеширование сохранённых артефактов, взаимные связи source↔screen и отклонение выходящих за incoming путей/junction. Настоящий Python-запуск контрольного Poker-портрета воспроизводит source PASS_WITH_ROUNDING и grid/overall FAIL; дата снимка и SHA-256 сохраняются.

Браузерная проверка локального пульта и финальные PNG находятся в `docs/validation/`. `browser-proof.json` описывает точный охват: вкладки, общая библиотека отдельно от продуктового контракта, ссылки на доказательства, сохранение пометки, отсутствие горизонтальной прокрутки при 390px и ошибок JavaScript. Эти результаты относятся к Верификатору, а не к качеству шахматного интерфейса.

Figma проверялась только на чтение: наличие двух указанных узлов, структура страниц библиотеки/макетов, наборы кнопок, поля ввода и локальные стили/коллекции переменных. Охват и ограничения перечислены в `docs/design-system-connection.md`.

При переносе в целевую папку скрипт независимо перечитывает каждый доставленный файл и сравнивает SHA-256. Дополнительно проверяются сохранённые хеши манифестов и каждого артефакта всех архивных аудитов. Точные количества и итог — `migration/verification.json`, список файлов — `migration/manifest.json`.

`profiles/poker/snapshots/state-2026-10-27.json` сохраняет исходный индекс истории. Рабочий `profiles/poker/data/state.json` после запуска сервиса может пополняться событиями, запусками и заметками. Хеши переноса фиксируют состояние на момент копирования; исходные ревизии остаются неизменяемыми.

Шахматы намеренно остаются INCOMPLETE: не заданы продуктовый контракт, композиция, Figma-страница сдачи и viewport-политика. Полный DS-аудит, runtime шахмат и одобрение дизайнов этой проверкой не выполнялись.
